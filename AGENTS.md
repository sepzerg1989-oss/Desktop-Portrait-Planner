# Project Working Rules

1. At the start of each new conversation, read the contents of `Projectbackground/` to understand the project context. When the task involves UI, also read `Projectbackground/design.md` for design requirements.
2. After completing a task, do not run `npm run build` for packaging unless the user explicitly asks for a build/package verification.
3. If an update has a significant impact on the software structure, update `Projectbackground/project_documentation.md` in a timely manner.
